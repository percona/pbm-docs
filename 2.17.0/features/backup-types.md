# Backup and restore types

You can use several types of database backups and restores to develop your backup strategy.

Not sure what exactly backup you need? The following diagram helps you decide:

The following table provides an overview of each type:

| Type                                                                                                                     | Version added                                                                | When to use                                                                                                                                                                                 | Supported deployments                                                                          | Percona Server for MongoDB                                                 | MongoDB Community / Enterprise Edition |

| [Physical](https://docs.percona.com/percona-backup-mongodb/2.17.0/features/physical.html) GA                             | 2.0.0                                                                        | - Full restore of a very large (e.g. Terabytes of data) dataset to a specific point in time with guaranteed data consistency - Faster restores compared to logical ones                     | Sharded clusters and non-sharded replica sets                                                  | Yes (starting with 4.2.15-16, 4.4.6-8 and higher, 5.0.x, 6.0.x and higher) | No                                     |
