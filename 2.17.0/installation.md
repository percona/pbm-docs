# Quickstart guide

Percona Backup for MongoDB (PBM) is an open source and distributed solution for consistent backups and restore of [MongoDB sharded clusters and replica sets](https://docs.percona.com/percona-backup-mongodb/2.17.0/details/deployments.html). [Learn how PBM works](https://docs.percona.com/percona-backup-mongodb/2.17.0/intro.html).

Find the list of supported platforms for Percona Backup for MongoDB on the [Percona Software and Platform Lifecycle](https://www.percona.com/services/policies/percona-software-platform-lifecycle#mongodb) page. Also, check [supported MongoDB versions](https://docs.percona.com/percona-backup-mongodb/2.17.0/details/versions.html).

## Tutorials

You can use any of the easy-install guides but **we recommend using the package manager of your operating system** for a convenient and quick way to try the software first.

**Package manager**

Use the package manager of your operating system to install Percona Backup for MongoDB:

- `apt` - for Debian and Ubuntu Linux
- `yum` - for Red Hat Enterprise Linux and compatible Linux derivatives

[Install from repositories](https://docs.percona.com/percona-backup-mongodb/2.17.0/install/repos.html)

**Docker**

Get our Docker image and spin up PBM for a quick evaluation.

Check the Docker guide for step-by-step guidelines.

[Run in Docker](https://docs.percona.com/percona-backup-mongodb/2.17.0/install/docker.html)

**Kubernetes**

**Percona Operator for Kubernetes** is a controller introduced to simplify complex deployments that require meticulous and secure database expertise.

Check the Quickstart guides how to deploy and run PBM on Kubernetes with Percona Operator for MongoDB.

[Deploy in Kubernetes Quickstart](https://docs.percona.com/percona-operator-for-mongodb/quickstart.html)

**Build from source**

Have a full control over the installation by building PBM from source code.

Check the guide below for step-by-step instructions.

[Build from source](https://docs.percona.com/percona-backup-mongodb/2.17.0/install/source.html)

**Manual download**

If you need to install PBM offline or prefer a specific version of it, check out the link below for a step-by-step guide and get access to the downloads directory.

[Install from tarballs](https://docs.percona.com/percona-backup-mongodb/2.17.0/install/tarball.html)
